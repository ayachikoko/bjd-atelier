# BJD Atelier · 寧々酱的娃娃工房

在浏览器里捏一只属于自己的 BJD 娃娃。所有部件都是**程序化 3D 生成**的——没有外部模型文件，改一个参数整只娃娃就跟着变。

## 玩法

八个维度自由组合：

| 维度 | 选项 |
|---|---|
| 尺寸 | 1/3 SD 60cm · 1/4 MSD 45cm · 1/6 YOSD 26cm · 1/12 15cm |
| 娃头 | 鹅蛋脸 · 尖下颌 · 婴儿肥 · 成熟颜 |
| 妆容 | 素颜清透 · 甜系粉调 · 哥特烟熏 · 晨光蜜桃（另有 4 种肤色） |
| 发型 | 长直 · 双马尾 · 波波头 · 丸子头 · 波浪卷（另有 6 种发色） |
| 服装 | 素体 · 洛丽塔裙 · JK 制服 · 哥特长裙 · 居家睡衣 |
| 鞋履 | 裸足 · 玛丽珍 · 长靴 · 凉鞋 · 运动鞋 |
| 姿势 | 标准站姿 · 乖巧并手 · 回眸一笑 · 抬手招呼 · 舒展 |
| 背景 | 奶油影棚 · 粉色卧室 · 暮色古堡 · 落日窗边 · 晨光花园 |

左上角有「随机搭配」「重置」「保存照片」，右下角可拖动旋转、滚轮缩放。

## 技术

- **纯前端**，three.js r169，无构建步骤，GitHub Pages 直接托管。
- **参数化素体**：头、躯干、四肢由剖面线（profile）旋转成型（`LatheGeometry`），球关节按关节位置生成，姿势 = 关节欧拉角预设——BJD 本来就是「转球关节」，所以姿势系统天然成立。
- **配件不穿模**：发壳、刘海、胸衣都由**同一份头部／身体剖面**推导（半径 + 偏移），所以头发永远贴合颅骨、衣服永远包住身体，不靠手工对位。
- **妆容分层**：虹膜是球面帽 + 极坐标纹理（不会出现「贴纸眼」），腮红／眼影是贴在脸面上的软贴片，唇与眉是跟随曲面生成的几何体。
- **树脂质感**：`MeshPhysicalMaterial` + clearcoat/sheen，环境光照由 canvas 渐变经 PMREM 生成，ACES 色调映射。

## 本地运行

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123/
```

> 必须用 HTTP 打开，`file://` 下 ES module 会被浏览器拦截。

## 取舍

这是**风格化树脂手办风**，不是照片级写实：追求的是「BJD 的手感」——球关节、圆润壳面、影棚打光、可换装——而不是复刻某个具体型号。蕾丝编织、布料物理、毫米级刺绣这类细节不在范围内。
